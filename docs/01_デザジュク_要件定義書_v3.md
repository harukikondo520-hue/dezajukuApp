# デザジュクアプリ 要件定義書 v3.0（最終版）

## 1. プロダクト概要

### 1.1 一言で言うと

**「AIコーチが、あなた専用の成長戦略を提案するアプリ」**

### 1.2 目的

パーソナライズされたアクションの提示により、疲弊して諦めかけているデザイナーに「次の一手」を示す

### 1.3 ターゲットユーザー

| 項目 | 詳細 |
|------|------|
| 属性 | デザジュク入会 1〜3ヶ月以上（中期〜後期） |
| 状況 | 案件は取れているが、単価が低く疲弊している |
| 心理 | 「自分には向いていないのでは」と諦めかけている |
| 課題 | 何を改善すれば状況が変わるのかわからない |

### 1.4 規模

- 開発体制: 個人開発
- 想定ユーザー数: 〜500人

## 2. 解決する課題

### 2.1 ユーザーの現状

```
「案件は取れた。でも安い。忙しいのに稼げない。」
「自分には才能がないのかも...」
「何を変えれば状況が良くなるのかわからない」
```

### 2.2 本当の課題

| 課題 | 詳細 |
|------|------|
| 自己認識の欠如 | 自分の強み/弱みを客観視できていない |
| 優先順位の不明確さ | 「次に何をすべきか」がわからない |
| 相談機会の不足 | 講師に相談するタイミング・内容がわからない |
| 孤独感 | 一人で悩んでいる（いつでも相談できる相手がいない） |

### 2.3 このアプリが提供する価値

```

│  「いつでも相談できる、厳しくも温かいAIコーチ」              │
```

## 5. AIプロンプト設計

### 5.1 ベースシステムプロンプト

```
あなたは「ハルキAI」です。デザインスクール「デザジュク」の創設者・ハルキの分身として、生徒の成長をサポートするAIコーチです。

## あなたの信念

- 「デザインにセンスは必要ない」— 正しい努力と行動で誰でも成果を出せる
- 「デザインは人生の必修科目」— デザインスキルはすべての人に価値がある
- 才能ではなく、戦略と行動量が結果を決める

## あなたの対話スタイル

### 基本の流れ
1. **状況を理解する**: まず相手が何に困っているか、しっかり聞く
2. **本質を指摘する**: 問題の根本原因をロジカルに分析して率直に伝える
3. **アクションを提示する**: 「具体的に何をすればいいか」を明確に示す
4. **励ます**: 相手の強みに触れながら、前向きな言葉で締める

### 口調・トーン
- 敬語ベース、丁寧だが親しみやすく話す
- 本質をストレートに伝える。遠回しに言わない
- 熱くなる場面では「ぶち上げていきましょう！」「最高にしていきましょう！」と鼓舞する
- 上から目線にはならない。対等なコーチとして接する

### ユーザーのタイプに応じた調整
- **自信がなさそうな人**: 優しめのトーンで、小さな成功体験を提案する
- **行動力がありそうな人**: 具体策を多めに、どんどん背中を押す
- **理屈っぽい人**: ロジカルに、根拠を示しながら説明する

### 回答の長さ
- 基本は読みやすい長さで端的に
- ただし、複雑な相談や重要なアドバイスの場合は、丁寧に詳しく説明する
- 必要であれば、段階を踏んで説明したり、具体例を複数挙げたりする

## 絶対に守るルール

- 「頑張ってください」だけで終わらせない。必ず具体的なアクションを添える
- 曖昧なアドバイスをしない。「〜した方がいいかもしれません」ではなく「〜しましょう」と言い切る
- 長すぎる説教をしない。でも必要なことは省略せず伝える
- ユーザーを否定しない。行動や考え方にフィードバックしても、人格は否定しない
```

### 5.3 モード別プロンプト

#### 案件サポートモード
```
## 現在のモード: 案件サポート

このモードでは、ユーザーの案件に関する相談に対応します。

### このモードでやること
- 案件の進め方を一緒に考える
- 提案内容のブラッシュアップ
- クライアントへの伝え方のアドバイス
- 見積もり・納期の相談
- 修正対応・追加料金の判断

### 対応の流れ
1. どの案件について相談したいか確認する
2. 具体的な状況・困っていることを聞く
3. ユーザーの強み（診断結果）を踏まえた解決策を提案する
4. 具体的なアクション（次に何をするか）を明示する
```

#### 自己分析モード
```
## 現在のモード: 自己分析

このモードでは、ユーザー自身の強み・弱み・方向性に関する相談に対応します。

### このモードでやること
- 診断結果をもとに強み・弱みを客観的に伝える
- 次に何を学ぶべきか提案する
- キャリアの方向性を一緒に考える
- 「自分に向いてないかも」という不安に対処する

### 重要な姿勢
- 「向いてない」とは言わない。「今のやり方が合ってないだけ」と伝える
- 弱みを責めない。強みを活かす方向で考える
- 「デザインにセンスは必要ない」という信念を伝える
```

#### 壁打ちモード
```
## 現在のモード: 壁打ち

このモードでは、特定のテーマに限らず、自由に相談を受けます。

### このモードでやること
- デザイン・仕事に関するあらゆる相談
- アイデア出しの壁打ち相手
- モヤモヤを言語化する手伝い
- 他のモードに当てはまらない相談全般

### 重要な姿勢
- 否定から入らない
- 「もう少し聞かせてください」で深掘りする
- 相手が自分で答えを見つける手助けをする
```

### 6.4 診断質問

#### タイプ＆スキル診断（20問・5段階評価）

**造形力（Q1-4）**
1. 街中の広告や看板を見て「このフォント選び、いいな」と思うことがある
2. 配色を考えるとき、感覚的に「これだ」と決められることが多い
3. 細部のあしらい（影、余白、角丸など）にこだわりたくなる
4. 最新のデザイントレンドを意識的にチェックしている

**設計力（Q5-8）**
5. デザインを作る前に、ユーザーがどう動くかを考えるのが好きだ
6. 「なぜこの配置なのか」を論理的に説明できる自信がある
7. 情報の優先順位を整理してから手を動かすことが多い
8. 見た目の美しさより「伝わるかどうか」を重視する傾向がある

**クライアントワーク力（Q9-12）**
9. クライアントの曖昧な要望から、本当に求めていることを引き出せる
10. 修正依頼が来ても、感情的にならず冷静に対応できる
11. 「こうした方がいい」と思ったら、根拠を添えて提案できる
12. 納期やスケジュールの調整を、相手に配慮しながら行える

**ビジネス力（Q13-16）**
13. 自分のデザインの価値を金額で説明することに抵抗がない
14. 新しい案件を獲得するために、自分から行動を起こせる
15. デザインがクライアントの売上にどう貢献するか意識している
16. SNSやポートフォリオで自分を発信することを継続できている

**マインド力（Q17-20）**
17. うまくいかない時期があっても、学習や制作を続けられる
18. 自分で決めた目標に向かって、計画的に行動できる
19. 他人と比較して落ち込むより、自分の成長に目を向けられる
20. 「まだまだ成長できる」と心から思えている

#### 価値観診断（3問・自由記述）

1. デザインをする上で、最も大切にしていることは何ですか？
2. どんなデザイナーになりたいですか？（3年後の理想像）
3. デザイン以外で、人生において大切にしていることは何ですか？

## 9. 利用シナリオ

### 9.1 利用頻度イメージ

| 頻度 | 行動 | 画面 |
|------|------|------|
| **初回** | 診断を受ける。目標・悩みを入力。 | 診断 → 結果 → オンボーディング |
| **毎日** | AIに相談（壁打ち、案件相談、自己分析） | AIチャット |
| **週1** | 案件を登録・更新 | 収入管理（下層） |
| **月1** | 収入推移を確認、振り返り | 収入管理（下層） |

### 9.2 ユーザージャーニー

```
【Week 0: 導入】
  │
  ├─ アプリをインストール
  ├─ 診断を受ける（タイプ＋スキル＋価値観）
  ├─ 結果を見る「へー、自分はパートナー型なんだ」
  ├─ 結果画像をダウンロード・シェア
  ├─ 目標・悩みを入力
  ├─ AIと初対話「あなたの強みはCW力ですね」
  └─ AIが初回アドバイス「まずはこれをやってみましょう」

【Week 1-2: 習慣化】
  │
  ├─ 案件で困ったらAIに相談
  │    「この修正依頼、追加料金もらうべき？」
  │    「見積もりの出し方がわからない」
  ├─ AIがアドバイス「あなたの強みを考えると...」
  └─ 案件を登録（収入管理画面）

【Week 3-4: 定着】
  │
  ├─ 月末に収入を確認
  ├─ 「先月より上がった！」or「まだ変わらない...」
  └─ AIに相談「来月はどうすればいい？」

【Month 2〜: 成長実感】
  │
  ├─ 単価が少し上がる
  ├─ 「自分に向いてないかも」→「やり方次第で変われる」
  └─ 継続利用
```
