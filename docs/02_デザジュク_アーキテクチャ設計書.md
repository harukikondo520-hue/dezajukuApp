### 2.2 状態管理設計

#### Zustand Store 構成

```typescript
// authStore.ts
interface AuthState {
  session: Session | null;
  loading: boolean;
  signIn: (email: string, password: string) => Promise<void>;
  signUp: (email: string, password: string, name: string) => Promise<void>;
  signOut: () => Promise<void>;
  initialize: () => Promise<void>;
}

// userStore.ts
interface UserState {
  user: User | null;
  loading: boolean;
  fetchUser: () => Promise<void>;
  updateUser: (data: Partial<User>) => Promise<void>;
}

// diagnosisStore.ts
interface DiagnosisState {
  currentQuestion: number;
  answers: Record<number, number>;
  result: DiagnosisResult | null;
  setAnswer: (questionId: number, value: number) => void;
  nextQuestion: () => void;
  prevQuestion: () => void;
  calculateResult: () => DiagnosisResult;
  saveDiagnosis: () => Promise<void>;
}

// chatStore.ts
interface ChatState {
  messages: ChatMessage[];
  mode: ChatMode;
  loading: boolean;
  conversationId: string | null;
  setMode: (mode: ChatMode) => void;
  sendMessage: (content: string) => Promise<void>;
  loadHistory: () => Promise<void>;
}

// projectStore.ts
interface ProjectState {
  projects: Project[];
  loading: boolean;
  fetchProjects: () => Promise<void>;
  addProject: (data: ProjectInput) => Promise<void>;
  updateProject: (id: string, data: Partial<Project>) => Promise<void>;
  deleteProject: (id: string) => Promise<void>;
}
```

<Routes>
  {/* 認証不要 */}
  <Route path="/login" element={<LoginPage />} />
  <Route path="/signup" element={<SignupPage />} />
  
  {/* 認証必要・オンボーディング */}
  <Route element={<PrivateRoute />}>
    <Route path="/diagnosis" element={<DiagnosisPage />} />
    <Route path="/diagnosis/result" element={<DiagnosisResultPage />} />
    <Route path="/onboarding" element={<OnboardingPage />} />

  {/* 認証必要・オンボーディング完了 */}
  <Route element={<PrivateRoute requireOnboarding />}>
    <Route element={<AppLayout />}>
      <Route path="/" element={<HomePage />} />
      <Route path="/chat" element={<ChatPage />} />
      <Route path="/profile" element={<ProfilePage />} />
    </Route>
    <Route path="/income" element={<IncomeManagementPage />} />
    <Route path="/profile/diagnosis" element={<DiagnosisDetailPage />} />
  </Route>
</Routes>

#### データベース (PostgreSQL)

```
詳細は「データベース設計書」を参照
```

#### Storage

```
バケット: avatars
  - ユーザーアバター画像
  - パス: {user_id}/avatar.{ext}
  - 公開設定: 認証ユーザーのみ読み取り可
```

#### Row Level Security (RLS)

```sql
-- users テーブル
CREATE POLICY "Users can view own data" ON users
  FOR SELECT USING (auth.uid() = id);

CREATE POLICY "Users can update own data" ON users
  FOR UPDATE USING (auth.uid() = id);

-- projects テーブル
CREATE POLICY "Users can manage own projects" ON projects
  FOR ALL USING (auth.uid() = user_id);

-- diagnosis_results テーブル
CREATE POLICY "Users can manage own diagnosis" ON diagnosis_results
  FOR ALL USING (auth.uid() = user_id);

-- chat_messages テーブル
CREATE POLICY "Users can manage own messages" ON chat_messages
  FOR ALL USING (auth.uid() = user_id);
```

## 6. パフォーマンス設計

### 6.1 フロントエンド最適化

| 手法 | 詳細 |
|------|------|
| コード分割 | React.lazy + Suspense |
| 画像最適化 | WebP 形式、適切なサイズ |
| キャッシュ | SWR パターン（Zustand + stale-while-revalidate） |
| バンドルサイズ | Tree shaking、動的インポート |

### 6.2 バックエンド最適化

| 手法 | 詳細 |
|------|------|
| インデックス | 頻繁にクエリされるカラム |
| クエリ最適化 | 必要なカラムのみ SELECT |
| 接続プール | Supabase 標準 |

### 6.3 AIチャット最適化

| 手法 | 詳細 |
|------|------|
| ストリーミング | Server-Sent Events で逐次表示 |
| コンテキスト最適化 | 必要な情報のみ送信 |
