# Dify チャットボット統合ガイド

このドキュメントでは、DezajukuアプリにDifyチャットボット（ハルキAI）を統合する方法を説明します。

## 前提条件

- Difyアカウントが作成済み
- Difyでチャットボットが作成済み

## 統合手順

### 1. Difyチャットボットの作成

1. [Dify](https://dify.ai/)にログイン
2. 新しいチャットボットアプリを作成
3. ナレッジベースにデザジュク関連の情報を追加
4. チャットボットの設定を完了

### 2. 埋め込みコードの取得

1. Difyのダッシュボードで作成したチャットボットを開く
2. 「公開」タブに移動
3. 「埋め込み」オプションを選択
4. 埋め込みURLをコピー

### 3. 環境変数の設定

プロジェクトの`.env`ファイルに以下を追加：

```bash
VITE_DIFY_CHAT_URL=https://your-dify-instance.com/chatbot/your-chatbot-id
```

**例:**
```bash
VITE_DIFY_CHAT_URL=https://udify.app/chatbot/abc123xyz456
```

### 4. アプリケーションの再起動

環境変数を追加後、開発サーバーを再起動：

```bash
npm run dev
```

## 動作確認

1. アプリケーションにログイン
2. AIチャットタブをクリック
3. 「ハルキAI」のチャット画面が表示されることを確認
4. Difyチャットボットが正しく埋め込まれていることを確認

## トラブルシューティング

### チャットボットが表示されない

- `.env`ファイルに`VITE_DIFY_CHAT_URL`が正しく設定されているか確認
- URLが正しいか確認
- 開発サーバーを再起動

### チャットボットが応答しない

- Difyのダッシュボードでチャットボットが公開されているか確認
- Difyのプランで埋め込み機能が利用可能か確認

## カスタマイズ

### チャットボットの名前変更

デフォルトでは「ハルキAI」として表示されます。変更する場合は、`src/pages/AIChat.tsx`を編集してください。

### スタイルのカスタマイズ

iframeのスタイルは`src/pages/AIChat.tsx`の92-96行目で調整できます。

## 注意事項

- Difyの無料プランでは埋め込み機能に制限がある場合があります
- チャットボットのトラフィックによっては、Difyの有料プランが必要になる場合があります
- セキュリティのため、DifyのAPIキーは`.env`ファイルに保存し、Gitにコミットしないでください

## サポート

問題が発生した場合は、以下を確認してください：

1. [Dify公式ドキュメント](https://docs.dify.ai/)
2. Difyのサポートチャンネル
