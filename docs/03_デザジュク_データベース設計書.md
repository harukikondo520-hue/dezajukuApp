## 2. テーブル定義

### 2.1 users（ユーザー）

ユーザーの基本情報を管理するテーブル。Supabase Auth と連携。

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|---------|---------|------|-----------|------|
| id | UUID | NO | - | 主キー（Supabase Auth の uid） |
| email | VARCHAR(255) | NO | - | メールアドレス |
| name | VARCHAR(100) | NO | - | 表示名 |
| avatar_url | TEXT | YES | NULL | アバター画像URL |
| goal | TEXT | YES | NULL | 目標（オンボーディングで入力） |
| current_problem | TEXT | YES | NULL | 現在の悩み（オンボーディングで入力） |
| onboarding_completed | BOOLEAN | NO | FALSE | オンボーディング完了フラグ |
| created_at | TIMESTAMPTZ | NO | NOW() | 作成日時 |
| updated_at | TIMESTAMPTZ | NO | NOW() | 更新日時 |

```sql
CREATE TABLE users (
  id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  email VARCHAR(255) NOT NULL UNIQUE,
  name VARCHAR(100) NOT NULL,
  avatar_url TEXT,
  goal TEXT,
  current_problem TEXT,
  onboarding_completed BOOLEAN NOT NULL DEFAULT FALSE,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- インデックス
CREATE INDEX idx_users_email ON users(email);

-- 更新日時自動更新トリガー
CREATE TRIGGER update_users_updated_at
  BEFORE UPDATE ON users
  FOR EACH ROW
  EXECUTE FUNCTION update_updated_at_column();
```

### 2.2 diagnosis_results（診断結果）

ユーザーの診断結果を保存するテーブル。

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|---------|---------|------|-----------|------|
| id | UUID | NO | gen_random_uuid() | 主キー |
| user_id | UUID | NO | - | ユーザーID（FK） |
| designer_type | VARCHAR(50) | NO | - | デザイナータイプ |
| design_skill | INTEGER | NO | - | 造形力スコア（0-100） |
| planning_skill | INTEGER | NO | - | 設計力スコア（0-100） |
| client_skill | INTEGER | NO | - | CW力スコア（0-100） |
| business_skill | INTEGER | NO | - | ビジネス力スコア（0-100） |
| mindset_skill | INTEGER | NO | - | マインド力スコア（0-100） |
| values_1 | TEXT | YES | NULL | 価値観1 |
| values_2 | TEXT | YES | NULL | 価値観2 |
| values_3 | TEXT | YES | NULL | 価値観3 |
| raw_answers | JSONB | NO | - | 回答の生データ |
| created_at | TIMESTAMPTZ | NO | NOW() | 診断日時 |

```sql
CREATE TABLE diagnosis_results (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  designer_type VARCHAR(50) NOT NULL,
  design_skill INTEGER NOT NULL CHECK (design_skill >= 0 AND design_skill <= 100),
  planning_skill INTEGER NOT NULL CHECK (planning_skill >= 0 AND planning_skill <= 100),
  client_skill INTEGER NOT NULL CHECK (client_skill >= 0 AND client_skill <= 100),
  business_skill INTEGER NOT NULL CHECK (business_skill >= 0 AND business_skill <= 100),
  mindset_skill INTEGER NOT NULL CHECK (mindset_skill >= 0 AND mindset_skill <= 100),
  values_1 TEXT,
  values_2 TEXT,
  values_3 TEXT,
  raw_answers JSONB NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- インデックス
CREATE INDEX idx_diagnosis_results_user_id ON diagnosis_results(user_id);
CREATE INDEX idx_diagnosis_results_created_at ON diagnosis_results(created_at DESC);
```

**designer_type の値**:
- `artist` - アーティスト型
- `strategist` - ストラテジスト型
- `partner` - パートナー型
- `business_designer` - ビジネスデザイナー型
- `growth` - グロース型
- `all_rounder` - オールラウンダー型

**raw_answers の構造**:
```json
{
  "q1": 5,
  "q2": 4,
  "q3": 5,
  ...
  "q20": 3
}
```

### 2.3 projects（案件）

ユーザーの案件情報を管理するテーブル。

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|---------|---------|------|-----------|------|
| id | UUID | NO | gen_random_uuid() | 主キー |
| user_id | UUID | NO | - | ユーザーID（FK） |
| name | VARCHAR(200) | NO | - | 案件名 |
| amount | INTEGER | NO | - | 金額（円） |
| status | VARCHAR(20) | NO | 'in_progress' | ステータス |
| client_name | VARCHAR(100) | YES | NULL | クライアント名 |
| project_type | VARCHAR(50) | YES | NULL | 案件種別 |
| work_hours | DECIMAL(5,1) | YES | NULL | 作業時間 |
| deadline | DATE | YES | NULL | 納期 |
| memo | TEXT | YES | NULL | メモ |
| created_at | TIMESTAMPTZ | NO | NOW() | 作成日時 |
| updated_at | TIMESTAMPTZ | NO | NOW() | 更新日時 |

```sql
CREATE TABLE projects (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  name VARCHAR(200) NOT NULL,
  amount INTEGER NOT NULL CHECK (amount >= 0),
  status VARCHAR(20) NOT NULL DEFAULT 'in_progress',
  client_name VARCHAR(100),
  project_type VARCHAR(50),
  work_hours DECIMAL(5,1) CHECK (work_hours >= 0),
  deadline DATE,
  memo TEXT,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  
  CONSTRAINT valid_status CHECK (status IN ('in_progress', 'completed', 'paid'))
);

-- インデックス
CREATE INDEX idx_projects_user_id ON projects(user_id);
CREATE INDEX idx_projects_status ON projects(status);
CREATE INDEX idx_projects_created_at ON projects(created_at DESC);
CREATE INDEX idx_projects_user_status ON projects(user_id, status);

-- 更新日時自動更新トリガー
CREATE TRIGGER update_projects_updated_at
  BEFORE UPDATE ON projects
  FOR EACH ROW
  EXECUTE FUNCTION update_updated_at_column();
```

**status の値**:
- `in_progress` - 進行中
- `completed` - 完了
- `paid` - 入金済み

**project_type の値**:
- `lp` - LP制作
- `banner` - バナー制作
- `logo` - ロゴ制作
- `web` - Webサイト制作
- `sns` - SNS画像
- `print` - 印刷物
- `other` - その他

## 4. Row Level Security (RLS)

### 4.1 RLS ポリシー

```sql
-- RLS を有効化
ALTER TABLE users ENABLE ROW LEVEL SECURITY;
ALTER TABLE diagnosis_results ENABLE ROW LEVEL SECURITY;
ALTER TABLE projects ENABLE ROW LEVEL SECURITY;
ALTER TABLE chat_sessions ENABLE ROW LEVEL SECURITY;
ALTER TABLE chat_messages ENABLE ROW LEVEL SECURITY;

-- users テーブル
CREATE POLICY "Users can view own data"
  ON users FOR SELECT
  USING (auth.uid() = id);

CREATE POLICY "Users can update own data"
  ON users FOR UPDATE
  USING (auth.uid() = id);

CREATE POLICY "Users can insert own data"
  ON users FOR INSERT
  WITH CHECK (auth.uid() = id);

-- diagnosis_results テーブル
CREATE POLICY "Users can view own diagnosis"
  ON diagnosis_results FOR SELECT
  USING (auth.uid() = user_id);

CREATE POLICY "Users can insert own diagnosis"
  ON diagnosis_results FOR INSERT
  WITH CHECK (auth.uid() = user_id);

-- projects テーブル
CREATE POLICY "Users can manage own projects"
  ON projects FOR ALL
  USING (auth.uid() = user_id);

-- chat_sessions テーブル
CREATE POLICY "Users can manage own sessions"
  ON chat_sessions FOR ALL
  USING (auth.uid() = user_id);

-- chat_messages テーブル（セッション経由でアクセス制御）
CREATE POLICY "Users can view own messages"
  ON chat_messages FOR SELECT
  USING (
    session_id IN (
      SELECT id FROM chat_sessions WHERE user_id = auth.uid()
    )
  );

CREATE POLICY "Users can insert own messages"
  ON chat_messages FOR INSERT
  WITH CHECK (
    session_id IN (
      SELECT id FROM chat_sessions WHERE user_id = auth.uid()
    )
  );
```

## 5. ビュー

### 5.1 月別収入サマリー

```sql
CREATE VIEW monthly_income_summary AS
SELECT
  user_id,
  DATE_TRUNC('month', created_at) AS month,
  COUNT(*) AS project_count,
  SUM(amount) AS total_income,
  AVG(amount) AS average_amount
FROM projects
WHERE status IN ('completed', 'paid')
GROUP BY user_id, DATE_TRUNC('month', created_at)
ORDER BY month DESC;
```

### 5.2 ユーザー最新診断結果

```sql
CREATE VIEW latest_diagnosis AS
SELECT DISTINCT ON (user_id)
  *
FROM diagnosis_results
ORDER BY user_id, created_at DESC;
```
