# Dezajuku アプリケーション 要件定義書

## 1. 概要

**Dezajuku**は、デザインスクールの受講生向け学習管理・収入トラッキングプラットフォームです。

### 1.1 目的
- デザイン案件の管理と収入追跡
- パーソナライズされた学習ロードマップの提供
- 動画教材による学習支援
- スキル診断によるデザイナータイプの可視化

### 1.2 技術スタック
- フロントエンド: React / TypeScript / Tailwind CSS
- バックエンド: Supabase (PostgreSQL / Auth)
- ビルドツール: Vite
- アイコン: Lucide React
- グラフ: Recharts

## 3. 画面詳細

### 3.1 オープニング画面

**概要**: アプリ起動時に表示されるスプラッシュ画面

**機能**:
- 3秒のロゴアニメーション動画を再生
- セッション中1回のみ表示（sessionStorageで管理）
- 動画読み込み失敗時は5秒でスキップ

---

### 3.2 ログイン画面

**概要**: 既存ユーザーの認証

**機能**:
- メールアドレス入力フィールド
- パスワード入力フィールド
- ログインボタン
- 新規登録ページへのリンク
- エラーメッセージ表示（認証失敗時）

**バリデーション**:
- メールアドレス: 必須、メール形式
- パスワード: 必須

---

### 3.3 サインアップ画面

**概要**: 新規ユーザー登録

**機能**:
- 名前入力フィールド（ローマ字、自動大文字変換）
- メールアドレス入力フィールド
- パスワード入力フィールド
- パスワード確認入力フィールド
- 登録ボタン
- ログインページへのリンク

**バリデーション**:
- 名前: 必須
- メールアドレス: 必須、メール形式、重複不可
- パスワード: 必須、6文字以上
- パスワード確認: パスワードと一致必須

---

### 3.4 オンボーディング画面

**概要**: 初回ログイン時のロードマップ選択とスキル診断

**ステップ1: ロードマップ選択**
- 2つのコースから選択:
  - 案件獲得コース（初案件獲得が目標の方向け）
  - 収入アップコース（既に案件がある方向け）
- コース説明と対象者情報を表示
- ラジオボタン形式で選択

**ステップ2: 確認画面**
- 選択したコースの確認
- 次のステップの案内（3項目）
- 戻るボタン / はじめるボタン

**完了時の処理**:
- ユーザープロフィールにロードマップIDを保存
- スキル診断ページへリダイレクト

---

### 3.5 スキル診断画面

**概要**: デザイナーのスキルとタイプを診断

**機能**:
- 20問の質問に5段階評価で回答
  - 造形力: 4問
  - 設計力: 4問
  - クライアントワーク力: 4問
  - ビジネス力: 4問
  - マインド力: 4問
- プログレスバー表示
- 前の質問に戻るボタン
- 次へ / 完了ボタン

**診断ロジック**:
- 各カテゴリのスコアを0-100点で計算
- 最高スコアのカテゴリに基づいてデザイナータイプを決定
  - 造形力トップ → アーティスト型
  - 設計力トップ → ストラテジスト型
  - CW力トップ → パートナー型
  - ビジネス力トップ → ビジネスデザイナー型
  - マインド力トップ → グロース型
  - バランス型 → オールラウンダー型

**完了時の処理**:
- 診断結果をデータベースに保存
- 診断結果ページへリダイレクト

---

### 3.6 診断結果画面

**概要**: スキル診断の結果を表示

**機能**:
- デザイナータイプカード
  - タイプ名
  - タイプの説明
  - タイプに応じたグラデーション背景
  - タイプアイコン
- レーダーチャート
  - 5つのスキル軸（造形力、設計力、CW力、ビジネス力、マインド力）
  - 各スキルのスコア表示
- ホームへ戻るボタン

**完了時の処理**:
- オンボーディング完了フラグをtrueに設定
- ホーム画面へリダイレクト

---

### 3.7 ホーム画面

**概要**: メインダッシュボード

#### 3.7.1 ヘッダー
- プロフィールアイコン（丸型、赤枠）
- 挨拶メッセージ（「おかえりなさい [名前]さん」）
- ログアウトボタン

#### 3.7.2 月収推移グラフ
- 直近6ヶ月の折れ線グラフ
- 赤系グラデーションのライン
- 各データポイントに金額表示（万円単位）
- 月ラベル表示

#### 3.7.3 収益統計（4カード）
| 項目 | アイコン | 説明 |
|------|----------|------|
| 今月月収 | Wallet（青） | 今月登録した案件の合計金額 |
| 最高月収 | Award（黄） | 直近6ヶ月の最高月収 |
| 平均月収 | Calculator（緑） | 収入がある月の平均 |
| 累計収益 | TrendingUp（赤） | 全案件の合計金額 |

#### 3.7.4 カリキュラム進捗
- プログレスバー（完了率%）
- 「X/Y 完了」の表示
- 動画が存在する場合のみ表示

#### 3.7.5 ロードマップ
- 現在のタスク表示（赤背景）
  - タスク名
  - 説明（あれば）
  - 完了ボタン（actionタイプのみ）
- 次のタスク表示（グレー背景）
- ロードマップ選択済みの場合のみ表示

#### 3.7.6 今月の案件一覧
- 案件カード（名前、金額）
- 編集ボタン / 削除ボタン
- 案件追加ボタン

#### 3.7.7 案件追加・編集モーダル
- 案件名入力
- 金額入力（円）
- ステータス選択（進行中 / 完了 / 入金済み）
- キャンセル / 追加（更新）ボタン

---

### 3.8 AIチャット画面

**概要**: AI学習アシスタント（Dify API連携予定）

**現在の状態**: 開発中（プレースホルダー応答）

**機能**:
- チャットメッセージ履歴表示
- ユーザーメッセージ（右寄せ、黒背景）
- アシスタントメッセージ（左寄せ、グレー背景）
- メッセージ入力フィールド
- 送信ボタン
- タイピングアニメーション（応答待ち時）

**よくある質問（初回表示時）**:
- LP制作の案件獲得方法を教えて
- デザイン単価を上げるコツは？
- ポートフォリオの作り方
- 営業文の書き方

---

### 3.9 プロフィール画面

**概要**: ユーザー情報とデザイナータイプの表示

#### 3.9.1 ヘッダー
- 戻るボタン（ホームへ）
- プロフィールアイコン
- ユーザー名（編集可能）
- ログアウトボタン

#### 3.9.2 デザイナータイプセクション
- デザイナータイプカード
  - タイプ名
  - タイプの説明
  - タイプに応じたグラデーション背景
  - タイプアイコン（右上に配置、端から10px間隔）
  - 再診断ボタン
- レーダーチャート
  - 5つのスキル軸（造形力、設計力、CW力、ビジネス力、マインド力）
  - 各スキルのスコア表示
- 診断を受けていない場合は診断受付カード表示

#### 3.9.3 バナーカルーセル
- 複数のバナー画像をスライドショー表示
- 自動スクロール（3秒ごと）
- ページインジケーター
- 次へ / 戻るボタン

#### 3.9.4 バッジセクション
- 獲得バッジの一覧表示
- バッジ画像
- バッジ名
- 獲得日時

## 7. デザインガイドライン

### 7.1 カラースキーム
- プライマリ: 赤系グラデーション（#ef4444 → #f97316）
- 背景: 白（#ffffff）
- テキスト: スレート系（#0f172a, #475569, #94a3b8）
- デザイナータイプ別カラー:
  - アーティスト型: 赤系（#ef4444）
  - ストラテジスト型: 青系（#3b82f6）
  - パートナー型: 緑系（#22c55e）
  - ビジネスデザイナー型: オレンジ系（#f59e0b）
  - グロース型: 紫系（#8b5cf6）
  - オールラウンダー型: グレー系（#6b7280）

### 7.2 レイアウト
- モバイルファースト設計
- ボトムナビゲーション（モバイル）
- フローティングナビゲーション（デスクトップ）
- 最大幅: 6xl（1152px）

### 7.3 コンポーネント
- 角丸: xl（12px）〜 2xl（16px）〜 3xl（24px）
- シャドウ: sm〜lg
- ボタン: 赤背景、白文字、ホバー時に色が濃くなる
