# Dezajuku アプリケーション 要件定義書

## 1. 概要

**Dezajuku**は、デザインスクールの受講生向け学習管理・収入トラッキングプラットフォームです。

### 1.1 目的
- デザイン案件の管理と収入追跡
- パーソナライズされた学習ロードマップの提供
- 動画教材による学習支援
- スキル診断によるデザイナータイプの可視化
- AI相談機能による学習サポート
- コミュニティ統計による相互刺激

### 1.2 技術スタック
- フロントエンド: React / TypeScript / Tailwind CSS
- バックエンド: Supabase (PostgreSQL / Auth)
- ビルドツール: Vite
- アイコン: Lucide React
- グラフ: Recharts
- AI連携: Dify（予定）

## 3. 画面詳細

### 3.1 オープニング画面

**概要**: アプリ起動時に表示されるスプラッシュ画面

**機能**:
- 3秒のロゴアニメーション動画を再生
- セッション中1回のみ表示（sessionStorageで管理）
- 動画読み込み失敗時は5秒でスキップ

---

### 3.2 ログイン画面

**概要**: 既存ユーザーの認証

**機能**:
- メールアドレス入力フィールド
- パスワード入力フィールド
- ログインボタン
- 新規登録ページへのリンク
- エラーメッセージ表示（認証失敗時）

**バリデーション**:
- メールアドレス: 必須、メール形式
- パスワード: 必須

---

### 3.3 サインアップ画面

**概要**: 新規ユーザー登録

**機能**:
- 名前入力フィールド（ローマ字、自動大文字変換）
- メールアドレス入力フィールド
- パスワード入力フィールド
- パスワード確認入力フィールド
- 登録ボタン
- ログインページへのリンク

**バリデーション**:
- 名前: 必須
- メールアドレス: 必須、メール形式、重複不可
- パスワード: 必須、6文字以上
- パスワード確認: パスワードと一致必須

---

### 3.4 オンボーディング画面

**概要**: 初回ログイン時のロードマップ選択とスキル診断

**ステップ1: ロードマップ選択**
- 2つのコースから選択:
  - 案件獲得コース（初案件獲得が目標の方向け）
  - 収入アップコース（既に案件がある方向け）
- コース説明と対象者情報を表示
- ラジオボタン形式で選択

**ステップ2: 確認画面**
- 選択したコースの確認
- 次のステップの案内（3項目）
- 戻るボタン / はじめるボタン

**完了時の処理**:
- ユーザープロフィールにロードマップIDを保存
- スキル診断ページへリダイレクト

---

### 3.5 スキル診断画面

**概要**: デザイナーのスキルとタイプを診断（基本診断 + 診断EX）

#### 3.5.1 基本診断（20問）

**機能**:
- 20問の質問に5段階評価で回答
  - 造形力: 4問
  - 設計力: 4問
  - クライアントワーク力: 4問
  - ビジネス力: 4問
  - マインド力: 4問
- プログレスバー表示
- 前の質問に戻るボタン
- 次へ / 完了ボタン

**診断ロジック**:
- 各カテゴリのスコアを0-100点で計算
- 最高スコアのカテゴリに基づいてデザイナータイプを決定
  - 造形力トップ → アーティスト型
  - 設計力トップ → ストラテジスト型
  - CW力トップ → パートナー型
  - ビジネス力トップ → ビジネスデザイナー型
  - マインド力トップ → グロース型
  - バランス型 → オールラウンダー型

#### 3.5.2 診断EX（5問）

**対象**: 基本診断完了者のみ

**質問内容**（各質問50文字以上の記述式）:
1. デザインで大切にしている価値観
2. 3年後のなりたい姿
3. 強みや得意な領域
4. 現在の課題や悩み
5. デザインスタイルや仕事の進め方

**完了時の処理**:
- 診断EXの回答をデータベースに保存
- プロフィールページで確認可能
- 将来的にAI分析によるレポート生成を予定

---

### 3.6 診断結果画面

**概要**: スキル診断の結果を表示

**機能**:
- デザイナータイプカード
  - タイプ名
  - タイプの説明
  - タイプに応じたグラデーション背景
  - タイプアイコン
- レーダーチャート
  - 5つのスキル軸（造形力、設計力、CW力、ビジネス力、マインド力）
  - 各スキルのスコア表示
- ホームへ戻るボタン

**完了時の処理**:
- オンボーディング完了フラグをtrueに設定
- 診断EXへ自動遷移（オンボーディング中）
- ホーム画面へリダイレクト（再診断時）

---

### 3.7 ホーム画面

**概要**: メインダッシュボード（2タブ構成）

#### 3.7.1 ヘッダー
- プロフィールアイコン（丸型、赤枠）
- 挨拶メッセージ（「おかえりなさい [名前]さん」）
- ログアウトボタン

#### 3.7.2 タブ構成

**マイページタブ**:
- 月収推移グラフ（直近6ヶ月）
- 収益統計（4カード）
  - 今月月収（青）
  - 最高月収（黄）
  - 平均月収（緑）
  - 累計収益（赤）
- カリキュラム進捗
- ロードマップタスク
- 今月の案件一覧
- 診断誘導バナー
  - 未診断者: 基本診断への誘導
  - 基本診断完了者: 診断EXへの誘導

**コミュニティタブ**:
- 今月の総収入（全ユーザー合計）
- 今月案件獲得数（全ユーザー合計）
- 今月平均単価
- 月間収益ランキング（TOP5）
  - 順位
  - ユーザー名
  - 今月の収益
  - デザイナータイプアイコン

#### 3.7.3 月収推移グラフ
- 直近6ヶ月の折れ線グラフ
- 赤系グラデーションのライン
- 各データポイントに金額表示（万円単位）
- 月ラベル表示

#### 3.7.4 カリキュラム進捗
- プログレスバー（完了率%）
- 「X/Y 完了」の表示
- 動画が存在する場合のみ表示

#### 3.7.5 ロードマップ
- 現在のタスク表示（赤背景）
  - タスク名
  - 説明（あれば）
  - 完了ボタン（actionタイプのみ）
- 次のタスク表示（グレー背景）
- ロードマップ選択済みの場合のみ表示

#### 3.7.6 今月の案件一覧
- 案件カード（名前、金額）
- 編集ボタン / 削除ボタン
- 案件追加ボタン

#### 3.7.7 案件追加・編集モーダル
- 案件名入力
- 金額入力（円）
- ステータス選択（進行中 / 完了 / 入金済み）
- キャンセル / 追加（更新）ボタン

---

### 3.8 AIチャット画面（ハルキAI）

**概要**: デザジュク創設者との対話体験

**機能**:
- Difyチャットボット埋め込み（iframe）
- 環境変数による制御（VITE_DIFY_CHAT_URL）
- Dify未設定時はプレースホルダーチャット表示
  - チャットメッセージ履歴表示
  - ユーザーメッセージ（右寄せ、黒背景）
  - アシスタントメッセージ（左寄せ、グレー背景）
  - メッセージ入力フィールド
  - 送信ボタン
  - タイピングアニメーション（応答待ち時）

**よくある質問（初回表示時）**:
- LP制作の案件獲得方法を教えて
- デザイン単価を上げるコツは？
- ポートフォリオの作り方
- 営業文の書き方

**ブランディング**:
- タイトル: 「ハルキAI」
- サブタイトル: 「デザジュク創設者と直接話そう」
- アイコン: 赤系グラデーション

---

### 3.9 プロフィール画面

**概要**: ユーザー情報とデザイナータイプの表示

#### 3.9.1 ヘッダー

**機能**:
- カード形式で表示
- デフォルトは要約（最初の100文字）
- 「全文を読む」ボタンで全内容を展開

  - あなたの強み
  - 現在の課題
  - デザインスタイル
- ハルキAIへの相談を促すヒント

#### 3.9.4 バナーカルーセル
- 複数のバナー画像をスライドショー表示
- 自動スクロール（3秒ごと）
- ページインジケーター
- 次へ / 戻るボタン

#### 3.9.5 バッジセクション

- SELECT / INSERT / UPDATE / DELETE を個別に定義

## 7. デザインガイドライン

### 7.1 カラースキーム
- プライマリ: 赤系グラデーション（#ef4444 → #f97316）
- 背景: 白（#ffffff）
- テキスト: スレート系（#0f172a, #475569, #94a3b8）
- デザイナータイプ別カラー:
  - アーティスト型: 赤系（#ef4444）
  - ストラテジスト型: 青系（#3b82f6）
  - パートナー型: 緑系（#22c55e）
  - ビジネスデザイナー型: オレンジ系（#f59e0b）
  - グロース型: 紫系（#8b5cf6）
  - オールラウンダー型: グレー系（#6b7280）
