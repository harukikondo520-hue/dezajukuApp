# Dezajuku アプリケーション 要件定義書

## 1. 概要

**Dezajuku**は、デザインスクールの受講生向け学習管理・収入トラッキングプラットフォームです。

### 1.1 目的
- デザイン案件の管理と収入追跡
- パーソナライズされた学習ロードマップの提供
- 動画教材による学習支援

### 1.2 技術スタック
- フロントエンド: React / TypeScript / Tailwind CSS
- バックエンド: Supabase (PostgreSQL / Auth)
- ビルドツール: Vite
- アイコン: Lucide React

## 3. 画面詳細

### 3.1 オープニング画面

**概要**: アプリ起動時に表示されるスプラッシュ画面

**機能**:
- 3秒のロゴアニメーション動画を再生
- セッション中1回のみ表示（sessionStorageで管理）
- 動画読み込み失敗時は5秒でスキップ

---

### 3.2 ログイン画面

**概要**: 既存ユーザーの認証

**機能**:
- メールアドレス入力フィールド
- パスワード入力フィールド
- ログインボタン
- 新規登録ページへのリンク
- エラーメッセージ表示（認証失敗時）

**バリデーション**:
- メールアドレス: 必須、メール形式
- パスワード: 必須

---

### 3.3 サインアップ画面

**概要**: 新規ユーザー登録

**機能**:
- 名前入力フィールド（ローマ字、自動大文字変換）
- メールアドレス入力フィールド
- パスワード入力フィールド
- パスワード確認入力フィールド
- 登録ボタン
- ログインページへのリンク

**バリデーション**:
- 名前: 必須
- メールアドレス: 必須、メール形式、重複不可
- パスワード: 必須、6文字以上
- パスワード確認: パスワードと一致必須

---

### 3.4 オンボーディング画面

**概要**: 初回ログイン時のロードマップ選択

**ステップ1: ロードマップ選択**
- 2つのコースから選択:
  - 案件獲得コース（初案件獲得が目標の方向け）
  - 収入アップコース（既に案件がある方向け）
- コース説明と対象者情報を表示
- ラジオボタン形式で選択

**ステップ2: 確認画面**
- 選択したコースの確認
- 次のステップの案内（3項目）
- 戻るボタン / はじめるボタン

**完了時の処理**:
- ユーザープロフィールにロードマップIDを保存
- オンボーディング完了フラグをtrueに設定
- ホーム画面へリダイレクト

---

### 3.5 ホーム画面

**概要**: メインダッシュボード

#### 3.5.1 ヘッダー
- プロフィールアイコン（丸型、赤枠）
- 挨拶メッセージ（「おかえりなさい [名前]さん」）
- ログアウトボタン

#### 3.5.2 月収推移グラフ
- 直近6ヶ月の折れ線グラフ
- 赤系グラデーションのライン
- 各データポイントに金額表示（万円単位）
- 月ラベル表示

#### 3.5.3 収益統計（4カード）
| 項目 | アイコン | 説明 |
|------|----------|------|
| 今月月収 | Wallet（青） | 今月登録した案件の合計金額 |
| 最高月収 | Award（黄） | 直近6ヶ月の最高月収 |
| 平均月収 | Calculator（緑） | 収入がある月の平均 |
| 累計収益 | TrendingUp（赤） | 全案件の合計金額 |

#### 3.5.4 カリキュラム進捗
- プログレスバー（完了率%）
- 「X/Y 完了」の表示
- 動画が存在する場合のみ表示

#### 3.5.5 ロードマップ
- 現在のタスク表示（赤背景）
  - タスク名
  - 説明（あれば）
  - 完了ボタン（actionタイプのみ）
- 次のタスク表示（グレー背景）
- ロードマップ選択済みの場合のみ表示

#### 3.5.6 今月の案件一覧
- 案件カード（名前、金額、ステータス）
- ステータス変更ドロップダウン
  - 進行中（青）
  - 完了（黄）
  - 入金済み（緑）
- 編集ボタン / 削除ボタン
- 案件追加ボタン

#### 3.5.7 案件追加・編集モーダル
- 案件名入力
- 金額入力（円）
- ステータス選択
- キャンセル / 追加（更新）ボタン

---

### 3.6 AIチャット画面

**概要**: AI学習アシスタント（Dify API連携予定）

**現在の状態**: 開発中（プレースホルダー応答）

**機能**:
- チャットメッセージ履歴表示
- ユーザーメッセージ（右寄せ、黒背景）
- アシスタントメッセージ（左寄せ、グレー背景）
- メッセージ入力フィールド
- 送信ボタン
- タイピングアニメーション（応答待ち時）

**よくある質問（初回表示時）**:
- LP制作の案件獲得方法を教えて
- デザイン単価を上げるコツは？
- ポートフォリオの作り方
- 営業文の書き方

---

### 3.7 動画講義画面

**概要**: 動画教材の一覧と視聴

#### 3.7.1 学習進捗
- プログレスバー（完了率%）
- 「X/Y 完了」の表示

#### 3.7.2 検索・フィルター
- 動画タイトル/説明の検索
- カテゴリフィルター（ドロップダウン）

#### 3.7.3 動画一覧
- 動画カード
  - 完了アイコン or 再生アイコン
  - タイトル
  - カテゴリタグ
  - 再生時間
- 完了済み動画は緑枠表示

#### 3.7.4 動画視聴モーダル
- YouTube埋め込みプレイヤー（またはUTAGE連携予定表示）
- 動画タイトル
- 説明文
- 閉じるボタン
- 視聴完了ボタン（未完了時のみ）

## 5. データベース設計

### 5.1 主要テーブル

#### users
| カラム | 型 | 説明 |
|--------|------|------|
| id | uuid | プライマリキー（auth.usersと連携） |
| name | text | ユーザー名 |
| roadmap_id | uuid | 選択したロードマップ |
| onboarding_completed | boolean | オンボーディング完了フラグ |
| last_login_at | timestamp | 最終ログイン日時 |

#### projects
| カラム | 型 | 説明 |
|--------|------|------|
| id | uuid | プライマリキー |
| user_id | uuid | ユーザーID |
| name | text | 案件名 |
| reward | integer | 報酬金額（円） |
| status | enum | 進行中/完了/入金済み |
| completed_at | timestamp | 完了日時 |

#### roadmaps
| カラム | 型 | 説明 |
|--------|------|------|
| id | uuid | プライマリキー |
| name | text | ロードマップ名 |
| description | text | 説明 |
| target_audience | text | 対象者 |
| order_index | integer | 表示順 |

#### tasks
| カラム | 型 | 説明 |
|--------|------|------|
| id | uuid | プライマリキー |
| roadmap_id | uuid | ロードマップID |
| title | text | タスク名 |
| description | text | 説明 |
| task_type | enum | video / action |
| video_id | uuid | 動画ID（videoタイプの場合） |
| order_index | integer | 表示順 |

#### user_tasks
| カラム | 型 | 説明 |
|--------|------|------|
| id | uuid | プライマリキー |
| user_id | uuid | ユーザーID |
| task_id | uuid | タスクID |
| completed | boolean | 完了フラグ |
| completed_at | timestamp | 完了日時 |

#### videos
| カラム | 型 | 説明 |
|--------|------|------|
| id | uuid | プライマリキー |
| title | text | タイトル |
| description | text | 説明 |
| youtube_id | text | YouTube動画ID |
| category_id | uuid | カテゴリID |
| duration | integer | 再生時間（秒） |
| order_num | integer | 表示順 |

#### video_progress
| カラム | 型 | 説明 |
|--------|------|------|
| id | uuid | プライマリキー |
| user_id | uuid | ユーザーID |
| video_id | uuid | 動画ID |
| completed | boolean | 完了フラグ |
| watched_percent | integer | 視聴率（0-100） |

#### categories
| カラム | 型 | 説明 |
|--------|------|------|
| id | uuid | プライマリキー |
| name | text | カテゴリ名 |
| description | text | 説明 |
| order_num | integer | 表示順 |

### 5.2 セキュリティ
- 全テーブルでRow Level Security (RLS) 有効
- ユーザーは自分のデータのみアクセス可能
- auth.uid()によるオーナーシップ検証

## 6. ユーザーフロー

```
[オープニング]
     |
     v
[ログイン] <---> [サインアップ]
     |
     v
[オンボーディング] (初回のみ)
     |
     v
[ホーム] <---> [AIチャット] <---> [動画講義]
   |
   +-- 案件管理（追加/編集/削除/ステータス変更）
   +-- 収益統計の確認
   +-- ロードマップタスクの確認・完了
```

## 7. デザインガイドライン

### 7.1 カラースキーム
- プライマリ: 赤系グラデーション（#ef4444 → #f97316）
- 背景: 白（#ffffff）
- テキスト: スレート系（#0f172a, #475569, #94a3b8）
- ステータス:
  - 進行中: 青（#dbeafe, #1e40af）
  - 完了: 黄（#fef3c7, #92400e）
  - 入金済み: 緑（#dcfce7, #166534）

### 7.2 レイアウト
- モバイルファースト設計
- ボトムナビゲーション（モバイル）
- フローティングナビゲーション（デスクトップ）
- 最大幅: 6xl（1152px）

### 7.3 コンポーネント
- 角丸: xl（12px）〜 2xl（16px）〜 3xl（24px）
- シャドウ: sm〜lg
- ボタン: 赤背景、白文字、ホバー時に色が濃くなる
